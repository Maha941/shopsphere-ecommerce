REST Endpoints Reference

GET /api/users Returns all users (Status: 200)
GET /api/users/:id Returns single user by ID (Status: 200 / 404)
POST /api/users Creates user with validation (Status: 201 / 400)
PATCH /api/users/:id Updates user partially (Status: 200 / 404 / 400)
DELETE /api/users/:id Deletes user from array (Status: 200 / 404)
POST /api/auth/signup User registration (Status: 201 / 400)
POST /api/auth/login User authentication (Status: 200 / 401 / 404)
